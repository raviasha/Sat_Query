# Run the 1,000-area pipeline

**Goal:** Process the verified Drive subset through the existing modules in order, inspect alignment, train using training areas, and evaluate class coverage on held-out test areas.

**Architecture:** Keep raw download, tensor preparation, frozen CROMA extraction, spatial coverage targets, model fitting, and evaluation as separate persisted stages. Every later stage checks the preceding manifest and file hashes. Use Google Colab and Drive; retain official area splits throughout.

## Execution sequence

- [x] Stage 1: Verify the ten downloaded ZIP receipts, extract them safely to temporary Colab storage, restore combined metadata after extraction, and call `satquery.prepare_croma.export_inputs` with batches of 32. Keep original integer reference maps. Validate shapes `(N,12,120,120)` / `(N,2,120,120)`, float32 normalized range, finite values, IDs, splits, channel order, CRS and source grids. Write the prepared stage under `MyDrive/SatQuery/pipeline-1000/prepared`.
- [x] Stage 2: Call `satquery.features` with the pinned official CROMA Base checkpoint, frozen evaluation/inference mode, bounded device batches. Store all six feature tensors and provenance in `pipeline-1000/features`; check 225 spatial tokens and dimension 768 for each area. Prefer a free GPU if available.
- [x] Stages 3–4: Call `satquery.targets.export_targets`. Independently recount all 225,000 tiles with simple nested loops over label pixels, check row-major token order and north-up projected 80 m bounds, and compare against vectorized targets. Verify counts across all 19 classes plus unlabeled sum to 64; fractions use denominator 64, not just labeled pixels. Audit fully/partly/unlabeled counts by split and class. Train/evaluate only fully labeled tokens under the current prediction-head contract.
- [x] Stage 5: Fit the separate linear coverage head on training areas only. Select epoch/configuration using validation areas; keep an explicit constant train-mean baseline. Save the chosen checkpoint and training configuration. Never select models using the test set.
- [x] Stages 6–7: Evaluate the frozen chosen head on test areas. Export per-class MAE/RMSE/bias in percentage points, present-class MAE, sample/token support, and fraction of predictions within 5 percentage points. Report dominant-class precision/recall/F1 as secondary categorical measurements; undefined values stay null. Quantify aggregate-metric uncertainty by resampling areas, not correlated tokens.
- [x] Inference reliability: keep predicted coverage distinct from confidence. Attach held-out per-class historical error/support to inference output. If adding per-prediction intervals, reserve separate calibration areas from validation before fitting/selecting; assess interval coverage on untouched test areas. Do not invent confidence from softmax coverage or `100 - MAE`.

## Constraints and checks

The downloaded imagery is a pinned unofficial pre-conversion; label reference maps are original. CROMA tokens are anchored to 8×8 input regions but include surrounding attention context. Spatial matching checks index/geometry agreement, not independent 80 m ground-truth accuracy. Record snow/cloud flags, masks, exclusions, and class support. Respect existing output protection: do not overwrite a completed export or bypass data validation. Preserve module separation and existing demo artifacts. New evaluation code requires numerical fixtures (known error values, absent classes, wrong alignment, split leakage) before live use.

## Completed run (2026-09-09)

All seven stages passed on Colab T4. The independent audit checked 14.4 million original map pixels and 4.275 million class counts. Eligible tokens: train 134,255; validation 44,848; test 44,723. Validation selected epoch 5 from 15 epochs. Held-out test dominant accuracy 53.8743%; coverage MAE 6.1553 pp versus train-mean baseline 9.2137 pp. Predictions for all 1,000 areas were saved and verified with a checkpoint-bound historical reliability report. Per-prediction confidence intervals were not added.
