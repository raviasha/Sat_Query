Observation 1

Separate files must end in _B01.tif … _B12.tif, or _VV.tif and _VH.tif.

Observation 2
ZIP instructions and request.json example

Put request.json at the ZIP root. Map every required TIFF and band index explicitly. No reference map is needed. Paths must be relative and every listed file must exist. 

{
  "schema_version": 1,
  "observations": [{
    "id": "scene-a",
    "modality": "SAR",
    "sensor": "Sentinel-1",
    "acquired": "2026-02-03",
    "radiometry": "db",
    "bands": {
      "VV": {"file": "scene_VV.tif", "band": 1},
      "VH": {"file": "scene_VH.tif", "band": 1}
    }
  }]
}
